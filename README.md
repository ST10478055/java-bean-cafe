#  Java Bean Café

A simple menu-based Java application built with Maven.
Users can earn points, redeem rewards, and check their balance.

---

##  Features

* Buy coffee (+10 points)
* Redeem reward (50 points)
* Check balance (name + points)
* Exit program
* Unit tests (JUnit)
* GitHub Actions (automated testing)

---

##  Technologies

* Java
* Maven
* JUnit 5
* GitHub Actions
